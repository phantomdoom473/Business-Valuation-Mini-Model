# Company Valuation Explorer

A simple web app: type a company name (like "Tesla"), it finds the ticker automatically,
pulls real financial data, and runs a DCF valuation — no coding required to use it.

# Why I Built it??

I wanted to understand what a company is actually worth, rather than what the market says it is worth on a given day. I started with Saudi Aramco. The arithmetic turned out to be the easy part. At an 8% discount rate the model returned roughly $1.5 trillion; at 9%, $1.25 trillion. A quarter of a trillion dollars moved on one input I had chosen because it looked reasonable. That gap is what the project ended up being about.
